# 输出模板参考

## 组件类型参考

| 组件类型 | 说明 | 适用场景 |
|---------|------|---------|
| table | 数据表格，支持排序、筛选、分页 | 列表展示、数据管理 |
| searchBar | 搜索栏，包含多个筛选条件 | 列表页顶部的查询区域 |
| form | 表单，包含多种输入控件 | 数据录入、编辑页面 |
| button | 按钮 | 各类操作触发 |
| tabs | 标签页切换 | 内容分类展示 |
| card | 卡片容器 | 信息分组展示、仪表盘 |
| chart | 图表（折线图、柱状图、饼图等） | 数据分析、统计看板 |
| modal | 模态弹窗 | 确认操作、表单填写、详情查看 |
| drawer | 侧边抽屉 | 详情面板、配置面板 |
| tree | 树形结构 | 组织架构、分类目录、权限树 |
| upload | 文件/图片上传 | 附件管理、图片上传 |
| richText | 富文本编辑器 | 内容编辑、文章撰写 |
| timeline | 时间线 | 操作日志、流程记录 |
| steps | 步骤条 | 分步引导、流程展示 |
| tag | 标签 | 状态标识、分类标记 |
| statCard | 统计卡片 | 数据概览、指标展示 |
