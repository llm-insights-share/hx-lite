# 设计需求2

这个系统分二部分：

HX维护系统，包括：维护组织HX配置、HX资产包。以及项目管理，项目HX的配置、人工审批工单等。

HX交付框架，配合cursor、trae等ide使用的框架。

- HX维护系统
    1. 初始配置seed生成，为企业初始化HX配置库。
    2. 企业HX配置管理，包括：profile、stage、task、guide、suite、sensor等的增删改查。
    3. 项目管理：创建项目，增加项目成员（及角色），为项目创建初始化HX配置。
    4. 项目产物管理：就像github一样，所有本地AI交付各阶段的产物都会提交到维护系统进行管理。并支持版本。
    5. 项目人工确认的工单管理，包括人工审批工单等。
- HX交付框架
    1. 本地项目初始化cli。
    2. 本地HX资产同步cli：从HX维护系统同步HX资产配置到本地。并更新安装到对应ide（cursor、trae等）
    3. 人工将产物提交到HX维护系统和创建工单的cli指令实现。
    4. 在ide可以使用全系统任务的command或skill。
