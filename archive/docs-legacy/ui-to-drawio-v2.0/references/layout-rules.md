## Drawio 特殊映射规则

基于实测 Ant Design Pro 页面的 drawio 渲染技巧：

1. **侧边栏边界过渡**: 在侧边栏和顶栏/内容区之间, 实际图像有一个 1-3px 的过渡带 (颜色渐变)。在 drawio 中简化: 纯色边界, 不模拟过渡。

2. **卡片阴影**: 实际设计有微弱的卡片阴影 (box-shadow)。在 drawio 原型中忽略阴影, 仅用 1px 边框。

3. **字体**: 实际使用 -apple-system / PingFang SC / Helvetica Neue。在 drawio 中无法指定字体族, 依赖系统默认。

4. **表格边框**: 实际表格仅底部有 1px 分隔线。在 drawio 中为每行单独生成 rect, 或使用单行文字模拟列对齐。

5. **图标处理**: drawio 不支持 SVG 图标。使用以下替代方案:
   - 菜单图标: 省略或用 `●` `◆` 等 Unicode 符号
   - 统计卡片图标: 小圆/矩形 + 颜色区分
   - 操作图标: 文字链接代替 (如 "编辑" "删除")

6. **多行文字**: drawio 中 `whiteSpace=wrap` 可启用自动换行, 但中文字符换行行为不一致。对于多行内容 (如通知摘要), 使用较小的字号 (12px) 和较大的 width 来避免换行问题。

7. **透明度**: drawio 不支持 alpha 通道。替换方案:
   - rgba(255,255,255,0.7) → #A6A6A6 (等效视觉效果)
   - rgba(0,0,0,0.85) → #262626
   - rgba(0,0,0,0.65) → #595959
   - rgba(0,0,0,0.45) → #8C8C8C
   - rgba(0,0,0,0.25) → #BFBFBF
