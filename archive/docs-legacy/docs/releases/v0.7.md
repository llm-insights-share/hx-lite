# HarnessX / hx-lite v0.7

**Tag:** `v0.7` · **npm version:** `0.7.0` · **Node:** ≥ 20

hx-lite v0.7 ships the **WebUI 组织/项目 HX 维护系统** and the companion **`nhx` delivery CLI** (isolated from `hx` / `hxhub`).

---

## Highlights

### WebUI（组织 HX + 项目 HX）

- 组织侧：Profile / Stage·Task、Guide / Sensor、Bootstrap、GitHub Hub 推送、资产晋升审批
- 项目侧：从组织 HX **初始化** / **增量同步**、Guide·Sensor·自定义 Task、GitHub 同步、操作日志
- 包：`webui/`（FastAPI + Vue）

文档：[WebUI README](../../webui/README.md) · [WebUI + nhx 使用手册](../webui-nhx-usage.zh-CN.md)

### nhx 交付 CLI

```bash
nhx login
nhx init --project <id|slug> --stages req,dev
nhx sync
nhx adapter install
```

- 从 WebUI 导出项目 HX 到本地 `.nhx/`
- IDE adapter / hooks / artifact 提交与人工审批联动
- 与现有 `hx` 路径隔离，可并行安装

文档：[packages/nhx/README.md](../../packages/nhx/README.md)

### 项目同步与操作日志

- `POST /api/projects/{id}/sync-config`：相对组织 HX 增量对齐（增/改/删组织资产；保留项目私有 Guide 与自定义 Task）
- 详情页操作日志：初始化、同步、成员、Guide/Sensor/Task 等写操作可追溯

## Install

```bash
git clone https://github.com/llm-insights-share/hx-lite.git && cd hx-lite
git checkout v0.7
npm install && npm install -g .

# WebUI
cd webui && ./start.sh
```

## Upgrade notes

- 新增可选组件：WebUI + `nhx`；既有 `hx` / `hxhub` 工作流保持可用
- 使用 WebUI 管理组织资产时，项目侧请先 **初始化配置**，日常用 **同步** 拉取组织变更
