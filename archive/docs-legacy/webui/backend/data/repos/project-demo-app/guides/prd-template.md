# PRD 模板

用于编写产品需求文档。请按章节填写；方括号为提示。

## 1. 背景与目标
- 业务背景：[简述]
- 本期目标：[可度量]
- 非目标：[明确不做]

## 2. 用户与场景
- 角色：[角色列表]
- 主场景：[路径简述]

## 3. 用户故事
- 作为…我希望…以便…
- 优先级：P0/P1/P2

## 4. 功能说明
- 页面/能力要点
- 字段与校验
- 权限

## 5. 验收标准
- Given / When / Then 或检查清单

## 6. 非功能需求
- 性能、安全、可用性、兼容性

## 7. 依赖与风险
- 外部依赖
- 风险与缓解

## 8. 里程碑
- 节点与交付物

## 9. 开放问题
- 问题 / 责任人 / 截止日期
