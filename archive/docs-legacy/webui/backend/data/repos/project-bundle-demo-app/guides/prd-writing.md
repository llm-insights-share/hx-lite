# PRD 撰写（prd-writing）

## 目的
产出可落地的产品需求文档，覆盖用户故事、交互要点与验收标准，支撑设计与开发。

## 适用场景
- 需求阶段 PRD 编写
- 重大变更的产品说明

## 工作步骤
1. 对齐业务理解与原型结论
2. 按模板组织背景、目标、用户故事、功能说明、非功能与里程碑
3. 为每条用户故事写清验收标准
4. 标明依赖、风险与开放问题
5. 走产品/业务确认

## 产出物
- docs/prd/PRD.md（或项目约定路径）

## 约束
- 不使用无法验证的模糊措辞作为验收标准
- 界面说明与原型保持一致

## 完成标准
- 含「用户故事」「验收标准」等必备章节
- 关键流程可被测试用例覆盖
